### 1.4 字面量 `已定`

### 1.5 最终类型清单 `已定` `已答`

```
void(none)  array(不是 list)  bool  char  int  float  string
```

> 记录里特别强调：**是 `array`，不是 `list`**。

**`void` 与 `none` 的关系（已澄清）**：

- **`void` 是类型**

## 2. 类型系统

### 2.1 总体目标 `已定`

类型系统的核心诉求是**定下内存布局**，规则为：

- **默认对齐**
- **强类型**
- **有限度的自动推导**，占位符是 **`let`**

### 2.2 数据类型行为 `已定`

| 类别 | 传递语义 |
|---|---|
| 简单类型 | 传值 |
| 复杂类型（如数组） | 传引用 |

> 参考 Python 的模型来设计。

**数组的一个特殊设计**：数组**被函数返回它的引用**（与 C++ 不同）。

### 2.3 引用与拷贝

**引用是别名** `已定`：

- 「引用是 alias（别名），真的就是一个单元不同的名字」
- 引用声明：`let &a = c;`
- 引用传参：`function gcd(a: &int, b: int) -> int { ... }`

**`const` 的位置是有意义的** `已答`：

- `const` 写在 `&` 前面还是后面，**语义不同**，对应**不同的认知 / 不同的含义**
- 因此 `const &array` 与 `&string const` **不是同一件事**，两者都合法，含义有区别
- `待定`：这两者各自的确切语义（是「引用本身不可变」vs「被引用对象不可变」这类区别）尚未展开 —— 后续课上补

**拷贝语义** `暂缓` （原文：拷贝先不管，做编译器的时候再想）：

- 原记录写：`a = c;`（c 是类对象）、`b = a;` —— 都是复制，即创建新对象，`b` 是 `c` 的副本
- ⚠️ 此条**暂不作为定论**，等实现编译器阶段再定

### 2.4 类 `已定`

```nova
class name {
    public { ... }
    protected { ... }
    private { ... }
}
```

成员按访问级别**分组**书写，组内可以混放字段和函数：

```nova
public {
    a: int;
    function f(a: int) -> int;
}
```

### 2.5 继承与构造 `已定`

- 继承语法：`class tiger <- public felid`
- 需要 **`override`** 关键字
- **构造函数不自动调 `super`** —— 必须**手动显式**调用 `super.__constructor__(...)`
  - 已核实：`inherit.nova:20` 写的就是 `super.__constructor__("tiger");`，与规则一致
- 本语言里构造函数名为 **`__constructor__`**
- 实例见 `../nova程序示例/inherit.nova`

### 2.6 内置类型系统的补充 `已定`

- **`string` 是内置类型**，并**补充进关键字表**

### 2.7 ABI `已定`

- 关注**二进制兼容**：不同版本、不同架构
- 链接时才引入，所以**必须包含符号表**

## 3. 表达式与语句

### 3.1 核心抉择：句 vs 表达 `已定`

课上对比了两条路线：

- C 的路线：「语句的值是最后一个表达式的值」
- **Nova 的选择：几乎一切都是表达式**

由此推出的规则：

- **块的值** = 块内最后一条表达式的值
- **赋值是表达式，但值为 `none`**
- **禁止级联赋值** —— `a = b = c` 非法
- 因此 `a = b;` 的结果是 `none`

### 3.2 运算符 `已定` `已答`

- 不要 `++` / `--`
- 不要 `+=` 这类复合赋值
- **不等号只用 `<>`** —— **不保留 `!=`**（EBNF 里同时收了 `!=`，属误记，需删）
- 类型转换写作 `type()` 形式
- **`::`**（作用域/命名空间访问，如 `math::sqrt`）
- `()`　`[]`　`.`　正负号　`not` 等

## 4. 控制结构

### 4.1 分支

```nova
if cond { }
```

- `if` **即使只有一个条件也强制要 `{ }`**
- `[ ]` 在语法描述中表示**可选**
- `if c1 { } elseif c2 { } ... else { }`
- **if 表达式的值** = 满足条件的那个分支里**最后一条语句的值**

### 4.2 `match` `已定`

记录里当场修正过一次，**以修正后的为准**：

```nova
match obj {
    pattern1 => { 语句1; }
    ...
    else => { ... }
}
```

- 不要 `case`，用 **`=>`**
- **`else` 就是 default 分支**
- `pattern` 可以是 **bool**，也可以是**单值**
- `obj` 可以是**单值、比较表达式、逻辑表达式**
- 实例见 `../nova程序示例/eqroot.nova`（`match d { d > 0 => {...} d == 0 => {...} d < 0 => {...} }`）

### 4.3 循环

```nova
while cond { }
```

- **没有 do-while**

```
for x in range(n, m, j) { ... }
for x in [1:10] { break; }
```

- **range 用 Python 风格 `range(n, m, j)`**（三参数：起、止、步长），**不是** `[n,m,j]` 字面量
- **`[i:j]` 是切片写法**，语义**左闭右开**
- **`已答` 分工明确了**：**切片用于索引，range 用于迭代** —— 两者不是同一个东西，不靠上下文消歧
- 实例见 `../nova程序示例/sort.nova`、`hanoi.nova`

### 4.4 跳转 `已定`

只有三个：**`return`**、**`break`**、**`continue`**

### 4.5 函数 `已定`

类型后置，无头文件：

```nova
function gcd(a: int, b: int) -> int {
    ...
}
```

对照 C++ `func 函数名(参数列表) -> 返回类型 { return 表达式; }` 来理解。

## 5. 数组（本节改动最多）

### 5.1 最终结论 `已定`

```nova
let a : array[int | n, m]
```

数组的语义包含三要素：**维度、长度、基类**。

- 「长度是数组定义的一部分」，**这一点与 C++ 不同**
- **不再用 `int[n]` 这种 C++ 写法**，重新设计
- `array` 关键字**保留**，但不写成 `array` 裸用；实际声明也可以落到 `int[1,10]` 形式
- 实例见 `../nova程序示例/sort.nova`：`let arr: array[int | 9] = [9, 3, 7, 5, 1, 8, 6, 4, 2];`

### 5.2 生成器语法 `已定` `已答`

- **不要 `[n,m,j]` 这种字面量**
- 改用 **Python-like `range(n, m, j)`**

### 5.3 演进过程（备查）

1. `int[n]` —— C++ 风格，**废弃**
2. `array[int; n, m]` —— 用分号分隔维度，**作废**
3. **`array[int | n, m]`** —— 定稿，用竖线

### 5.4 动态数组 `已答`

- **先不要**动态数组

## 6. 包管理、注释与标准库

### 6.1 包管理与构建 `已定`

- **有包管理**（`nvp`）
- **不要头文件**
- 实现方式：「包管理 下载 cpp 源码 现场编译」

### 6.2 注释 `已定` `已答`

- 普通注释用 **`#`**（sharp）
- 文档注释也用 **`#`**，交给 **doxygen** 生成
  - 依据：**doxygen 支持 Python**，而 Python 的文档注释正是 `#` 风格 —— 所以用 `#` 完全可以这么做
  - 之前怀疑的「`#` 与 doxygen 不兼容」**不成立，此问题关闭**

### 6.3 标准包与独立包 `已定` `已答`

- **`uni`** —— 标准包，包含 **io**、**range**、**字符串处理** 等
- **`math`** —— **另一个独立包**，与 `uni` 平级，不是 `uni` 的子模块
- 示例中的 `import math;` + `math::sqrt(...)`（`eqroot.nova`）即独立包用法

## 7. BNF 编写要求 `已定`

写 BNF 需要覆盖以下八项：

1. 字符集
2. 运算符集
3. 关键字
4. 标识符
5. 字面量
6. 表达式 `expr`
7. 语句 `（expr;）`
8. 类型系统

其中表达式与语句各自都要覆盖：

- **算术**
- **赋值**
- **控制语句**：4 分支 + 2 循环 + 3 跳转

> 4 分支 = `if` / `elseif` / `else` / `match`
> 2 循环 = `while` / `for-in-range`
> 3 跳转 = `return` / `break` / `continue`

## 8. 与 EBNF（`nova-bnf.md`）的对勘

### 8.1 一致项

- 逻辑运算符用关键字 `and` / `or` / `xor` / `not`
- 无 `++`/`--`、无复合赋值、无级联赋值
- 赋值表达式值为 `none`
- 块的值 = 最后一条语句的值
- `if`/`elseif`/`else`、`match`、`while`、`for-in-range`
- 花括号强制
- 类型后置、无头文件
- 类成员按 `public`/`protected`/`private` 分组
- `type` 作为类型别名

### 8.2 与笔记不符、EBNF 需回改的地方

> 判断原则：**笔记对，EBNF 错**。列出仅为待办清单。

| # | 项目 | 笔记（最终） | 现有 EBNF | 处理 |
|---|---|---|---|---|
| 1 | `range` 语法 | Python 风格 `range(n, m, j)` | `range_expression = "[" expr ":" expr "]"`（第 194 行） | **改 EBNF**：range 是函数式调用；`[i:j]` 另有切片含义 |
| 2 | 数组类型语法 | `array[int \| n, m]` | `array_type = type_spec "[" expr {"," expr} "]"`（第 114 行） | **改 EBNF**：加入 `\|` 分隔的基类/长度写法 |
| 3 | 不等号 | **只用 `<>`** | `equality_expr` 含 `!=`（第 148 行） | **删掉 EBNF 里的 `!=`** |
| 4 | `string` 关键字 | 是关键字、是内置类型 | 关键字表**没有** `string`（第 26–32 行） | **补进 EBNF** |
| 5 | `void` / `none` | `void` 是类型，`none` 是该类型的名字（值） | `basic_type` 把两者列为两个独立类型（第 111 行） | **改成：`void` 为类型，`none` 为字面量** |
| 6 | 动态数组 | 先不要 | EBNF 未涉及 | 无需改，备案 |

### 8.3 EBNF 完全没写的部分（规范缺口）

| # | 项目 | 说明 |
|---|---|---|

### A. 仍需补规范（笔记尚未展开）

1. **`const` 前后位置各自的语义**：已确认"有影响"，但「`const &T`」与「`&T const`」各自到底约束什么（引用自身不可变 vs 被引用对象不可变），还需一次课讲清。
2. **`[i:j]` 切片与 `range(n,m,j)` 的分工**：切片用于索引，range 用于迭代，但 `for in` 后面能否直接跟切片、消歧规则怎么写，未定。
3. **`::` 和 `import` 的完整语法**（`uni` 标准包如何组织、包名解析规则）。
4. **继承语法 `<-` 的完整规则**：`class tiger <- public felid` 里的 `public` 是什么意思（公开继承？），是否支持多重继承？
5. **元组赋值 `a, b = b, a;` 的语义**：右侧是否先全部求值再统一赋值？
6. **数组返回引用**的具体规则：返回的是引用还是副本？生命周期谁负责？
7. **`main` 的签名**：返回 `int`、参数可为空，返回值是否即退出码。
8. **`static`** 在关键字表里但无用例：静态成员如何声明、如何访问？
9. **`self` 的规则**：何时必须写、何时可省略？
10. **`async` / `await` / `yield`**：课上提到「支持多线程」，但只有关键字、没有语义 —— 线程模型是什么（真线程 / 协程 / green thread）？
11. **包管理「下载 cpp 源码现场编译」**：是否指 Nova 包携带 C++ 源码、由 `nvp` 现场构建再链接？符号表与名字修饰规则是什么？
12. **运算符重载被排除**后，自定义类型如何做 `==` / `<` 比较？是否只靠 `__to_string__` 这类钩子？
13. **未初始化变量的默认值**（`point.nova:14` 的 `let s: string;`）。
14. **`$` 前缀形参**是语言规则还是约定。
15. **`array` 类型的长度参数可否省略**（`print_arr(a: &array)`）。

### B. 我已按「最终结论」理解、请随时指正的

- `elseif` = `elif`，语法糖
- `type` = `typedef`
- 一切皆表达式，赋值表达式值为 `none`，所以禁止 `a = b = c`
- `match` 的 `else` 即 default，pattern 可是 bool 或单值
- `void` 是类型、`none` 是其值
- 拷贝语义**尚未定论**（已在第 9 节标为暂缓，勿当作已定）
