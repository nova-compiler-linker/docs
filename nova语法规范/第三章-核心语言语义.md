## 3. 已确认结论总表

下表只作导航，具体规则以各模块文件为准。

| 范围 | 已确认结论 |
|---|---|
| Q01–Q03 | 未初始化声明可以省略初始化器，但读取前必须通过确定性初始化检查；无类型且无初始化器的 `let` 非法 |
| Q04–Q10 | `const` 是绑定只读；类型别名等价；作用域为包、文件、函数、块；允许遮蔽；包级只允许编译期常量 |
| Q11–Q12 | 普通引用只能绑定稳定左值；`&T const` 参数可在调用期间借用临时值，但任何引用都不能逃出来源生命周期 |
| Q13–Q25 | 声明不是值；块有值；无值控制流为 `void/none`；左值/右值二分；表达式语句保留副作用 |
| Q26–Q37 | 隐式提升为 `char → int → float`；`bool` 只参与逻辑；数值异常 trap；字符串按内容相等，用户类按身份相等 |
| Q38–Q47 | 赋值结果为 `void/none`；支持多目标赋值；循环是语句；`range` 支持一至三参数；条件必须为 `bool` |
| Q48–Q57 | `let` 局部推导；数组字面量共同提升；函数只按位置传参；函数和成员函数允许重载；不支持函数值、lambda、闭包 |
| Q58–Q60 | 简单类型传值，类和数组传引用；用户类和数组按引用返回；入口为无参 `main() -> int` |

## 4. 本轮收口的边界

为了让第三章可以被编译器和编辑器直接使用，本模块包同时给出以下最小设计：

1. `const &T` 是只能绑定稳定左值的只读视图；`&T const` 是调用期间只读的 const 引用参数，也可以绑定字面量或临时值，但临时生命周期不得逃出调用。二者不产生不同的重载签名。
2. `string` 使用句柄表示；参数、返回和赋值都复制句柄，不隐式深拷贝。
3. 值语境中的 `if`/`match` 必须有覆盖所有路径的值分支；语句语境允许省略 `else`，结果为 `void/none`。
4. 其余数值运算沿公共提升类型检查；`float → char` 先向零截断，再按 ASCII 0–127 检查。
5. 多目标赋值要求左右数量相等；先取全部目标地址、再取右值、最后按顺序写入，重复地址按最后一次写入结果保留。
6. 非 `void` 函数所有可达路径必须返回；数组越界、除零、数值越界和零步长统一 trap。
7. 定长数组的长度是类型的一部分；`length()` 返回运行时元素总数；不引入动态数组和隐式切片复制。

这些规则优先保证示例可表达、语法可解析、诊断可定位、ABI 可固定。若与旧草案冲突，以本模块包和用户已确认的 Q 结论为准；合并到 `nova-spec.md` 前仍把本包视为第三章工作稿。

## 6. 其他分支的冲突处理

- `origin/chapter2-dev` 的补充稿把未初始化变量设为零值、把 `int` 溢出设为回绕，并取消函数重载；这些都不覆盖本章的示例和 Q01/Q33/Q54 结论。
- `origin/doc/class-module-async` 支持成员和模块级重载，但只按精确类型匹配；本章保留重载，同时加入已经确认的 `char → int → float` 提升排序。
- 两个分支都采用“补充说明文档”承载边界，而不是直接把所有设计塞进主规范；本模块包沿用这一合并方式。
