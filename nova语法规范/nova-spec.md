## 1. 词法

### 1.1 字符集 `✔`

```
ASCII 可打印字符 + @ + $
```

### 1.2 标识符 `✔`

```
identifier = ( letter | "_" | "$" ) { letter | digit | "_" | "$" }
```

- 不得以数字开头
- 不得与关键字重名

### 1.3 注释 `✔`

- **`#` 行注释**，普通注释与 doxygen 文档注释统一用 `#`
- 依据：doxygen 支持 Python 风格

### 1.4 关键字 `✔`

```
and      array    async    await    bool     break    char     class
const    continue else     elseif   false    float    for      function
if       import   in       int      let      match    none     not
or       override private  protected public   return   self     static
string   super    true     type     void     while    xor      yield
```

**两个语法糖**

| 关键字 | 等价于 |
|---|---|
| `elseif` | `elif` |
| `type` | `typedef` |

> `import` 于本次回填补入（协调 S-14）；`async` / `await` / `yield` 的语法与语义由异步章定义，本规范仅登记词法地位。

### 1.5 字面量 `✔`

| 类型 | 字面量 |
|---|---|
| `bool` | `true` `false` |
| `char` | `'a'` |
| `int` | `123` |
| `float` | `1.5`（**IEEE754** 存储，格式见 §2.6） |
| `string` | `"a"` |
| `void` | **`none`** |
| `array` | `[1, 2, 3]` |

> **`void` 是类型，`none` 是该类型的值。** 二者不是两个类型。

### 1.6 运算符 `✔`

```
算术    +  -  *  /  %
关系    <  >  <=  >=  ==  <>          # 不等号只有 <>，无 !=
逻辑    and  or  xor  not             # 关键字形式，无符号形式
赋值    =                             # 仅普通等号
其他    ::  .  ()  []  正负号  &  type()   # type() 为类型转换
```

**明确没有** `++`　`--`　`+=` 等复合赋值　运算符重载　位运算　`?:`

**运算符优先级与结合性**（协调 S-22，高→低；同级左结合，赋值右结合）：

```
1  后缀 ( ) [ ] .            6  ==  <>
2  一元 - + not              7  and
3  * / %                     8  xor
4  + -                       9  or
5  < > <= >=                 10 = （含多目标赋值）
```

> 完整表与细则见第二章 2.4.8。`type()` 为类型转换的元记法，落地写法是调用形式 `T(expr)`（第二章 2.6.7.2）。

## 2. 类型

### 2.1 类型集合 `✔`

```
void   bool   char   int   float   string   array
```

- **强类型 + 有限自动推导**，占位符 `let`
- **`string` 是内置类型**
- **是 `array`，不是 `list`**；`array` 是关键字
- 类型分两大类：**值类型**（`void` `bool` `char` `int` `float`）与**类类型**（`class`，**`array` 归结为它**，**`string` 亦为类类型**，S-08）

### 2.2 内存与 ABI `✔`

- **默认对齐**
- 关注**二进制兼容**：跨版本、跨架构
- 链接期引入，**必须携带符号表**
- 各类型的**字节数、对齐、可用运算**见 §2.6

### 2.3 传递语义 `✔`

| 类别 | 语义 |
|---|---|
| 简单类型 | 传值 |
| 复杂类型（数组等） | 传引用（参照 Python 模型） |
| 数组作为返回值 | **返回引用**（与 C++ 不同） |

### 2.4 引用 `✔`

引用是**别名**：「一个单元的不同名字」。

```nova
let &a = c;                          # 引用声明
function gcd(a: &int, b: int) -> int # 引用传参
```

**`const` 的位置有意义**，不是笔误（协调 S-09 定稿）：

| 写法 | 含义 |
|---|---|
| `const &T` | **被引用对象只读**：只能绑定稳定左值，经该引用不可写 |
| `&T const` | **调用期间的只读参数视图**：可绑定稳定左值、字面量或临时值；临时值不得逃出调用 |

- 两者**含义不同**、均合法；三种引用形状（`&T` / `const &T` / `&T const`）**不产生**不同的重载签名。
- 细则（绑定检查、生命周期）见第二章 2.6.6。

### 2.5 拷贝 `?`

暂缓，实现编译器阶段再定。已定部分：赋值/传参/返回只复制句柄（§2.3），**无隐式拷贝**；独立副本必须显式构造（第四章 6.5 [14]）。

### 2.6 类型细节：字节 / 对齐 / 运算 `✔`

| type | byte | alignment | operation |
|---|---|---|---|
| `bool` | 1 | 1 | 逻辑；`==` `<>` |
| `char` | 1 | 1 | 算术/比较须**显式** `int(c)`（S-03）；其余同 `int` |
| `int` | 4 | 4 | 算术；与 `float` 混合自动升 `float`；溢出 **trap**（S-02） |
| `float` | 8 | 8 | 算术；**IEEE754 binary64** |
| `void` | 0 | 1 | 无；`none` 无运行时表示（D-26） |
| `string` | 16 | 8 | 句柄 `{ptr, length}`；`==` `<>` 按内容（S-08） |
| `class`（**`array` 归结为它**） | 视成员数量 | 最大成员的对齐 | `==` `<>` 按引用同一性 |

- `void` **不占存储**（0 字节），alignment 为 1；不可作数组基类
- **对齐通例**：`alignment = byte`（`void`、`class` 除外）（§9.2 第 15 条已裁决）
- 类类型的大小**视成员数量**，alignment 取**最大成员的对齐**；成员按声明顺序、vptr 置对象头部（第四章 6.11）
- 本表的 `operation` 列指**内置运算符**；类类型（`class`、`array`、`string`）**不参与内置运算**（唯一例外：`string` 的 `==`/`<>`），能力由下面的**接口**提供
- 隐式提升链 `char → int → float` 用于赋值、实参匹配、重载排序、算术/比较中的 `int → float`、以及 `return` 加宽到返回类型（S-29）；**`char` 不得自动提升入算术**（须显式 `int(c)`，S-03）。分支类型统一另按 S-15（完全同型）。类类型仅隐式向上转换、无显式 `type()`（S-28）。

**类类型的接口**（结构化定义见同目录 **`nova-types.yaml`**）

| 类类型 | attributes | operations |
|---|---|---|
| `array` | `length`、`internal_storage` | `length() -> int`、`[index] -> reference` |
| `string` | `length`、`internal_storage` | `length() -> int`、`[index] -> reference`、`[n:m] -> &string`、`format(fmt, args...) -> void` |

- `[index]` 取到的是**引用**（别名，§2.4）；`string` 的 `[n:m]` 切片取到的是 **`&string`**，**左闭右开**（§5.3）；`array` **无切片**（S-07）
- `length` 属性 ≡ `length()` 方法（同一访问两种拼写）；`array` 的 `length()` 返回**全维元素总数**（S-07）
- `format`：一次性初始化写入（`point.nova` 依赖，第二章 2.6.4.1）
- 越界行为：**trap**（§9.2 第 8 条已裁决，第二章 2.10.3）

## 3. 数组

### 3.1 类型语法 `✔`

```nova
let a : array[int | n, m]
```

- 数组语义 = **维度 + 长度 + 基类**
- **长度是数组定义的一部分**（与 C++ 不同）
- **不用** C++ 的 `int[n]` 写法
- `array` 关键字保留
- **`array` 归结为类类型（`class`）**，布局与大小规则见 §2.6
- 多维下标用**逗号全维** `a[i, j]`，一次消费全部维度；**无部分下标、无行视图**（协调 C-1/S-07）
- `array` **无 `[n:m]` 切片**（S-07）；`length()` 返回全维元素总数
- 形参可省略长度 `&array`（数组顶类型，接受任意基类/长度，第二章 2.6.4.2）

### 3.2 动态数组 `✗`

先不要。

## 4. 表达式

### 4.1 总原则 `✔`

**几乎一切都是表达式。**

| 规则 | 内容 |
|---|---|
| 块的值 | 块内**最后一条表达式**的值；块以语句结尾或为空则值为 `none`（类型 `void`） |
| 赋值的值 | 赋值是表达式，其值为 **`none`**（类型 `void`） |
| 级联赋值 | **禁止**：`a = b = c` 非法 |
| 因此 | `a = b;` 的结果是 `none` |
| `if` 的值 | 所选中分支块的值；作表达式时 `else` 强制、分支完全同型（S-15） |
| 控制结构 | `if` / `match` 本身也是表达式 |
| 语句封闭清单 | `let`/`const`/`type`/`import`/函数类声明/`return`/`break`/`continue` 是**语句**、无值（D-17） |
| 多重赋值 | `a, b = b, a`：先取址、后取值、再写入；类型 `void`（第二章 2.7.7 / 第三章 3.2.5） |

## 5. 语句

### 5.1 分支 `✔`

```
if cond { }
if c1 { } elseif c2 { } else { }
```

- **`{ }` 强制**，即使只有一条语句
- 条件必须为 `bool`，**无真值转换**（`if x` 其中 `x: int` 非法，须写 `if x <> 0`）

### 5.2 `match` `✔`

```nova
match obj {
    pattern => { ... }
    else    => { ... }
}
```

| 项 | 规则 |
|---|---|
| `obj` | 单值、比较表达式、逻辑表达式 |
| `pattern` | 比较模式（独立求值判真）或值模式（与 obj 做 `==`）；同一体内不混用 |
| `else` | 即 default 分支 |
| 无 `case` | 用 `=>` |

> 匹配算法（按模式形态分派、自上而下首命中）见第二章 2.8.3。

### 5.3 循环 `✔`

```nova
while cond { }
for x in range(n, m, j) { ... }
for x in arr { ... }
```

| 规则 | 内容 |
|---|---|
| 无 `do-while` | |
| **range** | Python-like `range(n, m, j)`，**用于迭代**；**语言内建构造**（S-21），非一等值 |
| **切片 `[i:j]`** | **用于索引**（仅 `string`），**左闭右开** |
| 无 `[n,m,j]` 字面量 | |
| 可迭代对象 | `range` 调用、`array`、`string`、切片（S-24）；循环变量为**只读副本**（S-06） |
| 步长为零 | trap（S-13） |

### 5.4 跳转 `✔`

```
return    break    continue
```

- `break` / `continue` **只作用于循环**，不跳出 `match`（S-25）
- 非 `void` 函数所有可达路径必须 `return`（第三章 3.4.1）

### 5.5 声明 `✔`

```nova
function gcd(a: int, b: int) -> int { ... }   # 类型后置，无头文件
let a: int = 10;
const limit: int = 10;                        # 绑定只读；包级 const 须编译期常量
type MyInt = int;
```

- 函数省略 `-> T` 时从带值 `return` 推导（S-16）
- 函数**允许重载**（S-04）：签名 = 参数类型列表；精确匹配优先，其次 `char→int→float` 提升排序
- `let x: T;` 创建未初始化槽位，读取前须通过确定性初始化检查（S-01）

## 6. 类 `✔`

```nova
class name {
    public    { ... }
    protected { ... }
    private   { ... }
}
```

- 组内可混放字段与函数
- 继承：`class tiger <- public felid`
- 重写：`override`
- 构造函数：**`__constructor__`**
- **构造函数不自动调 `super`，必须手动显式调用**：
  `super.__constructor__("tiger");`
  > 细化（2026-09-24，S-30）：该规则针对**显式**构造函数，**无例外**；唯一豁免是**隐式生成的无参构造函数**——有基类时自动调用基类的无参构造函数（第四章 §6.5 [8]），基类无可用的无参构造时该类必须显式声明构造函数。原「基类有无参构造时显式构造也可省略」的提案按已定结论否决。
