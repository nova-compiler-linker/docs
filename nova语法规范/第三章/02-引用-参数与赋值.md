# 3.2 引用、参数与赋值

## 结论

### 3.2.1 左值与引用

左值表示稳定存储位置，右值表示值或临时对象。左值不自动拥有写权限。

普通引用 `&T` 是对象的别名，只能绑定：

- 变量或参数；
- 可访问的类成员；
- 数组元素；
- 索引表达式的结果（`a[i]` 返回的元素引用；Nova 无指针，不存在解引用语法）；
- 生命周期已经由规则保证的引用返回值。

普通引用不能绑定字面量、临时值或普通值返回结果。`&T const` 参数是本章唯一例外：它可以在调用期间借用字面量或临时值，但不能把该临时值返回或保存。所有引用的生命周期都不能超过被引用对象；返回局部变量引用必须在编译期拒绝。

### 3.2.2 `const` 引用

```nova
function print_arr(a: const &array) -> void { ... }
function use_name(name: &string const) -> void { ... }
```

- `const &T`：通过该别名不能写入被引用对象，只能绑定稳定左值。
- `&T const`：调用期间只读的 const 引用参数，可以绑定稳定左值，也可以绑定字面量或临时值；临时对象的生命周期最多延伸到本次调用，不能从函数返回或保存。
- 两种写法都不是新的运行时对象，也不参与重载签名区分。

`sort.nova` 的 `print_arr(a: const &array)` 因而可以读取元素但不能排序；`inherit.nova` 的 `&string const` 可以接收字面量 `"tiger"`，再把内容复制到成员 `name`。

### 3.2.3 参数、返回和复制

| 类型 | 参数和结果语义 |
|---|---|
| `bool`、`char`、`int`、`float` | 复制值 |
| 用户自定义类、`array`、`string` | 复制句柄，指向同一对象/缓冲区 |
| 显式 `&T` | 复制别名，不复制对象 |

类、数组和字符串的赋值与传参一致：复制句柄，不隐式深拷贝。需要独立副本时由标准库提供显式复制函数，本章不引入隐式拷贝构造。

用户自定义类和数组作为函数结果时返回句柄；显式引用结果仍需通过生命周期检查。`string` 也按句柄返回，以兼容 `point.nova` 的 `__to_string__() -> string`。

### 3.2.4 赋值目标

可写稳定左值才可以作为赋值目标：

```nova
x = 1;          # 变量
p.x = 1.0;      # 可写成员
a[i] = 0;       # 数组元素
r = 2;          # 通过引用别名写入被引用对象
```

`const` 绑定、`const &T` 视图和只读成员都拒绝写入。赋值表达式的类型为 `void`，值为 `none`；级联赋值非法。

### 3.2.5 多目标赋值

```nova
a, b = b, a;
a[i], p.x = p.x, a[i];
```

规则固定为：

1. 左右目标数量必须相等；
2. 从左到右求出所有目标地址；
3. 从左到右求出所有右值；
4. 按目标顺序写入。

目标可以重复或通过不同别名指向同一地址；这种情况下最后一次写入结果保留。地址快照保证交换示例不受写入顺序影响。

### 3.2.6 `for` 循环变量

循环变量取得当前元素的值：

- 基础类型复制值；
- 类、数组、字符串复制句柄；
- 对循环变量重新赋值不会修改原集合元素；
- 需要修改集合时使用数组下标或显式引用。

## 实现约束

### `nvc`

- 每个表达式携带值类别、存储位置和写权限三项信息。
- 引用类型检查记录来源对象和生命周期区间；函数返回时检查区间是否覆盖调用者使用点。
- 多目标赋值生成两个临时列表：`target_addresses` 和 `rhs_values`，最后执行写回。
- 句柄赋值不生成深拷贝调用；显式复制函数才分配新对象。

### `nvld`

- 引用参数按机器地址传递；句柄参数按固定句柄布局传递。
- 类、数组和字符串的句柄布局必须写入 ABI 文档，符号名不因句柄复制改变。

### 编辑器连接器

补全和悬停信息显示“可读/可写/只读别名”三种状态；对 `const &T` 的赋值错误在赋值号位置报告，而不是延迟到后端。
